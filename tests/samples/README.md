# Fichiers d'exemple (non versionnés)

Les NEF sont lourds (55 Mo) et ignorés par git. Les tests qui en ont besoin sont
ignorés s'ils manquent. Pour les récupérer :

```bash
curl -sSL -o tests/samples/D850-14bit-lossless.NEF \
  https://raw.pixls.us/data/Nikon/D850/Nikon-D850-14bit-lossless-compressed.NEF
```
